## Code Style

### Double Quotes
Use double quotes for all strings in JS/TS/Svelte. Enforced by ESLint and Prettier.

### Semicolons Required
All statements must end with semicolons. Enforced by ESLint and Prettier.

### 4-Space Indentation
Frontend code uses 4-space indentation (ESLint indent=4, Prettier tabWidth=4).

### TypeScript Strict Mode
TypeScript configured with `strict: true`, `noImplicitAny: true`, `forceConsistentCasingInFileNames: true`. All variables and parameters must have explicit types.

### Unix Line Endings
All source files must use Unix-style (LF) line endings. Enforced by ESLint.
